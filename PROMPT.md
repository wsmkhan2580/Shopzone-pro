## Prompt 1 — The Direct One

> Build me a complete E-Commerce app called ShopZone using React, React Router, and Context API.
> I want a home page, shop page, product detail page, cart page, login page, checkout page, and
> contact page. Fetch products from dummyjson.com. Add a cart with add/remove/quantity controls.
> Save the cart to localStorage. Add a fake login with a Guest button and protect the checkout
> page so only logged in users can access it. Give me every file with full code and comments.

**Best used when:** You know exactly what you want and just need it built fast.

---

## Prompt 2 — The Phased One

> I want to build a React E-Commerce SPA called ShopZone in three phases.
> Phase one is routing — set up React Router with home, shop, contact, and a dynamic product
> page using useParams. Phase two is cart state — use Context API and useReducer to manage
> the cart globally, show a badge on the navbar, and build a cart page with totals.
> Phase three is advanced — persist the cart in localStorage, add mock authentication with a
> Login as Guest button, and protect the checkout route. Clean folder structure, comments
> in code, dark theme UI.

**Best used when:** You want the project built in logical stages that are easy to follow and understand.

---

## Prompt 3 — The Portfolio One

> Help me build a portfolio-worthy E-Commerce project in React called ShopZone.
> It should impress recruiters. Use React Router v6 for navigation, Context API for the cart
> and auth state, and fetch real product data from the dummyjson API. I need add to cart,
> a cart badge, localStorage persistence, a protected checkout page, and a mock login.
> Make the design dark and professional. Give me the full code for every single file
> so I can copy paste it into VS Code.

**Best used when:** You are building this specifically to show on your resume or GitHub profile.

---

## Prompt 4 — The Learning One

> I am learning React and want to build a real project to practice routing, Context API,
> and localStorage. Build an E-Commerce app called ShopZone. Use React Router for page
> navigation including a dynamic product detail route. Use Context API with useReducer
> for the shopping cart. Add localStorage so the cart saves on refresh. Add a simple guest
> login and a checkout page that redirects to login if the user is not authenticated.
> Add comments everywhere so I can understand the code.

**Best used when:** You are still learning and want to understand every line, not just copy it.

## Prompt 5 — The Interview Prep One

> Build a React E-Commerce SPA that covers the most common React interview topics.
> The project is called ShopZone. It should use React Router with a dynamic route,
> Context API with useReducer, a protected route that redirects unauthenticated users,
> localStorage for persistence, and a custom hook pattern. Fetch products from dummyjson.com.
> Include a Navbar with a cart badge and login status. Full code, clean structure, good comments.

**Best used when:** You are preparing for React interviews and want one project that covers all the key concepts interviewers ask about.

## Prompt 6 — The Casual One

> Can you build me a shopping app in React? Call it ShopZone. I want pages for home, shop,
> a single product, cart, login, checkout, and contact. Pull products from dummyjson.
> Let me add things to a cart and see the count in the navbar. Save the cart to localStorage
> so it doesn't disappear. Make login just a guest button, nothing real. Block checkout
> unless the user is logged in. Dark theme, looks clean, full code please.

**Best used when:** You want a relaxed, conversational tone in your prompt without overthinking the structure.

---

## Prompt 7 — The Structured One

> Create a complete React project called ShopZone with this exact structure:
> a /components folder with Navbar, ProductCard, ProtectedRoute, and Footer.
> A /contexts folder with CartContext and AuthContext.
> A /pages folder with Home, Shop, ProductDetail, Cart, Checkout, Login, and Contact.
> A /utils folder with a currency formatter.
> Use React Router v6, Context API, useReducer for the cart, localStorage persistence,
> and mock auth. Fetch from dummyjson.com. Give me the full code for every file.

**Best used when:** You want full control over the folder structure and file naming from the start.

## Prompt 8 — The Feature List One

> Build an E-Commerce React app called ShopZone with these features:
> product listing from dummyjson API, search and category filter on the shop page,
> dynamic product detail page with image gallery, add to cart with quantity controls,
> cart total calculation, cart badge on navbar, localStorage cart persistence,
> mock guest login, protected checkout route with redirect, order confirmation screen

**Best used when:** You think in terms of features and want to make sure nothing gets missed.

## Prompt 9 — The Minimal One

> React E-Commerce SPA. Name: ShopZone. Stack: React Router v6, Context API, dummyjson API.
> Pages: Home, Shop, Product Detail, Cart, Login, Checkout, Contact.
> Features: add to cart, cart badge, localStorage persistence, guest login, protected checkout.
> Folder structure: components, contexts, pages, utils.
> Full code for all files. Dark theme. Comments in code.

**Best used when:** You prefer short, dense prompts and want to pack maximum information into minimum words.

## Prompt 10 — The Storytelling One

> I want to build ShopZone, an online store where users can browse products, add them to
> a cart, and check out. A user lands on the home page, goes to the shop, clicks a product
> to see details, adds it to the cart, sees the cart count go up in the navbar, visits the
> cart page to review items, tries to checkout but gets redirected to login, clicks
> Login as Guest, gets sent back to checkout, fills out the form, and sees a confirmation.
> Build this full flow in React using React Router and Context API.
> Save cart to localStorage. Full code.

**Best used when:** You think in terms of user journeys and want the app to feel like a real, end-to-end experience.
